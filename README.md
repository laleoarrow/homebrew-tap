# laleoarrow Homebrew Tap

## Install iData

```bash
brew install --cask laleoarrow/tap/idata
```

Or tap first, then install:

```bash
brew tap laleoarrow/tap
brew install --cask idata
```

## Upgrade

```bash
brew upgrade --cask idata
```

## Uninstall

```bash
brew uninstall --cask idata
```
